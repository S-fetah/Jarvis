# Real-Time Documentation Lookup

## Workflow

1. **Identify Package & Version:** Extract the exact library name and target version from project manifests (`package.json`, `pyproject.toml`, etc.).
2. **Target Official Doc Portals:** Prefer canonical sources (e.g. `docs.nestjs.com`, `vite.dev`, `electronjs.org`) over blog posts or outdated forum replies.
3. **Pin Modern API Syntax:** Verify breaking changes between major versions before drafting code.
4. **Citation:** Include the direct doc link in the explanation.
